# Security Policy

## Supported Versions

This is a personal project. Only the latest code on the `main` branch is considered current.

## Reporting a Vulnerability

For non-sensitive reports, open a GitHub issue if issues are enabled for this repository.
Do not put exploit details, private data, or credentials in a public issue. There is
currently no private security-reporting channel configured for this project.

This project is maintained in spare time, so there is no guaranteed fix timeline.
